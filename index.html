Selected Publications

NeurIPS'26 Workshop Context-Grounded Data Curation and Gate-First RL Reward Design for SQL Autocomplete

Yueqin Yin*, Paul Dong*, Anni Li*, Yite Wang*, Arun Ponnusamy, Jaeseong Lee, Chiu Wah So, Mingyuan Zhou, Yuxiong He, Khalid Bijon, Zhewei Yao

OpenReview / Code (Coming Soon)

TL;DR

Autocomplete models trained on editing logs learn to guess, because the logged completion often depends on information not yet visible at the cursor. We trim each SFT target to its longest context-inferable prefix, keep empty targets as silence labels, and in RL place deterministic abstention and grounding gates before a graded LLM-judge reward, which avoids the silence collapse of a judge-only reward. The deployed 4B dense model raised live acceptance from 17.8% to 26.35% over the previous 30B-A3B MoE while cutting median latency by 71%.

EMNLP Findings'26 Mitigating Exploration Bias in RL for Multi-Instruction Following

Mian Zhang*, Yueqin Yin*, Kaiyu He, Peilin Wu, Xinlu Zhang, Mingyuan Zhou, Zhiyu Zoey Chen

Paper / Code

TL;DR

When a prompt contains several instructions and the reward counts how many are satisfied, RL keeps improving the easy instructions while the hard ones barely move. We propose two metrics that measure this exploration bias, then reduce it in two stages: Behavioral Bootstrapping, a short rejection-sampling fine-tuning that activates hard instructions before RL, and Scarcity-Aware Rewards, which weight each instruction by how rarely it is satisfied. Beats the cumulative-reward baseline by up to 9.2 points on IFBench.

ACL Findings'26 ContextCheck: Sentence-Level Faithfulness Verification with Context-Aware Disambiguation

Yueqin Yin, Yaxi Li, Xin Liu, Xun Wang, Kaiqiang Song, Simin Ma, Shujian Liu, Sathish Reddy Indurthi, Haoyun Deng, Pengcheng He, Mingyuan Zhou, Song Wang

Paper / Code (Coming Soon)

TL;DR

Checks each generated sentence against the source document while reading the preceding sentences to resolve pronouns, references, and ellipsis, removing the separate decontextualization step of prior pipelines. Earlier context is used only to disambiguate; evidence comes only from the source. Gains 10+ Macro-F1 points on three new context-dependent benchmarks and matches or beats 8B-scale verifiers on 14 standard single-sentence datasets.

TMLR'25 Segmenting Text and Learning Their Rewards for Improved RLHF in Language Model

Yueqin Yin*, Shentao Yang*, Yujia Xie, Ziyi Yang, Yuting Sun, Hany Awadalla, Weizhu Chen, Mingyuan Zhou

Paper / Code

TL;DR

A single reward per response is too sparse for RLHF, and a single token is too small to carry meaning. We split responses into semantically complete segments using the SFT model's entropy, learn segment-level rewards from ordinary sequence-level preferences, and stabilize PPO with location-aware reward normalization and within-segment reward interpolation. Outperforms sequence-, sentence-, and token-level reward variants on AlpacaEval 2.0, Arena-Hard, and MT-Bench.

ACL Findings'25🏆 Best Paper Award at DataWorld @ ICML 2025 KODCODE: A Diverse, Challenging, and Verifiable Synthetic Dataset for Coding

Zhangchen Xu, Yang Liu, Yueqin Yin, Mingyuan Zhou, Radha Poovendran

Paper / Code / Website

TL;DR

A synthetic coding dataset of 447K question–solution–test triplets from 12 sources. Each solution is verified by executing its unit tests, and hard problems get extra attempts so they are not filtered out. Models fine-tuned on KodCode reach state-of-the-art results on HumanEval(+), MBPP(+), BigCodeBench, and LiveCodeBench, and the data also supports RL with verifiable rewards.

arXiv'2402 Relative Preference Optimization: Enhancing LLM Alignment through Contrasting Responses across Identical and Diverse Prompts

Yueqin Yin*, Zhendong Wang*, Yi Gu, Hai Huang, Weizhu Chen, Mingyuan Zhou

Paper / Code

TL;DR

DPO only compares two responses to the same prompt. RPO also contrasts responses across semantically related prompts, weighting each pair by prompt similarity, so it can learn from both paired and unpaired preference data. Outperforms DPO, IPO, and KTO on Anthropic-HH, OpenAI Summarization, and AlpacaEval 2.0.

arXiv'2405 Self-Augmented Preference Optimization: Off-Policy Paradigms for Language Model Alignment

Yueqin Yin*, Zhendong Wang*, Yujia Xie, Weizhu Chen, Mingyuan Zhou

Paper / Code

TL;DR

Preference alignment without paired preference data or an external reward model. SAPO builds its own negatives by regenerating segments of chosen responses, using an EMA model and a replay buffer to keep training pairs fresh as the policy improves. Matches or exceeds DPO, ORPO, and SPIN on the Open LLM Leaderboard, IFEval, MT-Bench, and AlpacaEval 2.0.

CVPR'22 TransEditor: Transformer-Based Dual-Space GAN for Highly Controllable Facial Editing

Yanbo Xu*, Yueqin Yin*, Liming Jiang, Qianyi Wu, Chengyao Zheng, Chen Change Loy, Bo Dai, Wayne Wu

Paper / Code / Website

TL;DR

A Transformer-based dual-space GAN that lets two latent spaces interact through a cross-space interaction mechanism, so the structure (e.g., pose) and texture (e.g., style) of a face can be edited independently. Improves controllability and identity preservation on CelebA-HQ and FFHQ.
